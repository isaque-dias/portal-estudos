    PowerShell¶

    Estimated time to read: 1 minute

    Estudo estruturado de PowerShell, começando pelos fundamentos de administração do Windows (necessários antes de automatizar qualquer coisa) e avançando para a linguagem de scripting propriamente dita.

    Módulos¶

    • Fundamentos de Windows para PowerShell — sistema de arquivos NTFS e permissões, serviços, usuários/grupos e Active Directory, rede básica
    • PowerShell — filosofia de objetos, variáveis, condicionais, loops, arrays, hash tables e cmdlets
