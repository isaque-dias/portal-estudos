# Sobre

Este é um espaço de estudos técnicos em construção contínua. Aqui documento, de forma estruturada, o que venho aprendendo em banco de dados, automação, sistemas corporativos, APIs, infraestrutura e desenvolvimento.

O conteúdo é publicado aos poucos, conforme cada tópico é estudado e consolidado — não é uma documentação finalizada, e sim um registro vivo de progresso.

## Como está organizado

- **SQL** — modelagem, consultas e bancos relacionais
- **PowerShell** — administração e automação de sistemas Windows
- **PL/SQL** — procedures, funções e lógica no banco de dados
- **APIs** — REST, integrações e contratos de serviço
- **C# / .NET** — desenvolvimento de sistemas corporativos
- **Firewall** — segurança de rede e infraestrutura
- **Linux** — administração, shell e operação de sistemas
- **Python** — automação e engenharia de dados
